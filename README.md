# Ham exam trainers

Radio-themed study games for the US amateur radio Technician, General, and Amateur Extra exams,
using the official NCVEC question pools (public domain). Built with Claude.

Start here in any new session: **read `SPEC.md`, then `TRACKER.md`, then `ARTIFACTS.md`.**

- `SPEC.md` = how everything works and must look, the study loop, family pages, checks.
- `TRACKER.md` = what's done and what's next.
- `ARTIFACTS.md` = where each trainer is published.
- `exams/` = each exam's site files, notes, and raw data.
- `families/` = "Still confused?" family pages, one layer per exam.
- `sources/` = official pool PDFs.
- `tools/` = pool verification and app test scripts.
